# stats

几个数字。**滚动到可见时会从 0 数上去**，而且能正确处理前缀、后缀和小数。

```homepage-stats
columns: 3
stats:
  - 16 | 区块类型
  - 95 | 内置图标
  - 0 | 前端依赖
```

## 属性

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `stats` | 列表 | 必填 | 条目列表。别名 `items` |
| `animate` | 布尔 | `true` | 数字滚动。和插件的 `count` 选项是「与」的关系 |
| `columns` | 整数 | 自动 | 列数 |
| `min_cols` | 长度 | `13em` | 单条最小宽度 |

## 单条字段

`|` 简写按 **`数值 | 标签 | 图标`** 的顺序填：

| 位置 | 字段 | 说明 |
| --- | --- | --- |
| 1 | `value` | 数值。别名 `count` |
| 2 | `label` | 说明文字（别名 `desc` `title`） |
| 3 | `icon` | 图标名或图片路径 |

```homepage-stats
columns: 4
stats:
  - 12 | 只有数值和标签
  - 4.8 | 小数会保留一位 | star-outline
  - 99.9% | 百分号会识别成后缀
  - $1,200 | 货币符号会被当成前缀
```

## 数字是怎么被解析的

数值会被拆成 **前缀 / 数字 / 后缀** 三部分，只对中间那段做动画：

| 你写的 | 前缀 | 数字 | 后缀 | 动画结果 |
| --- | --- | --- | --- | --- |
| `16` | — | `16` | — | 0 → 16 |
| `4.8` | — | `4.8` | — | 0.0 → 4.8（一位小数） |
| `99.9%` | — | `99.9` | `%` | 0.0% → 99.9% |
| `$1,200` | `$` | `1,200` | — | $0 → $1,200 |
| `约 30+` | `约` | `30` | `+` | 约 0+ → 约 30+ |
| `v2` | `v` | `2` | — | v0 → v2 |

```homepage-stats
columns: 3
title: 前后缀
stats:
  - $1,200 | 货币 | simple/pypi
  - 约 30+ | 带中文前缀 | clock-outline
  - v2 | 版本号 | package-variant-closed
```

**小数位数是数字里的小数位数**，不是固定两位——`4.8` 会数到一位小数，
`12` 就是整数。

## 关掉数字滚动

```homepage-stats
columns: 3
animate: false
title: animate false
stats:
  - 16 | 区块类型
  - 95 | 内置图标
  - 0 | 前端依赖
```

```homepage-stats
columns: 2
title: 不能动画的数值会原样显示
stats:
  - 免费 | 没有数字就原样显示
  - 无限 | 同上
```

## 细节

- **不能解析成数字的 `value` 会原样显示**，不会报错。所以 `免费` / `无限`
  这类值可以直接写。
- **数字滚动需要 `prefers-reduced-motion` 允许**，用户关掉了动效时它就直接
  显示最终值。
- 插件选项 `count: false` 可以整站关掉滚动，`animate: false` 只关这一块。
- 空位：`- blank` 占位置但不画东西。
