# split

左右多栏，每栏是一段独立的 Markdown。用一行只有 `===` 的行来分栏。

```homepage-split
title: 两栏（默认带一根分隔线）
---
### 左边

第一栏的正文，可以用任何 Markdown。

- 列表
- `代码`

===

### 右边

第二栏同样是完整的一页 Markdown。
```

## 属性

| 属性 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `ratio` | 轨道 | 等分 | 列宽，见下。别名 `columns` |
| `reverse` | 布尔 | `false` | 左右整栏对调 |
| `divider` | 布尔 | 两栏时 `true` | 栏与栏之间的竖线 |
| `sticky` | 布尔 | `false` | 第一栏跟随滚动 |
| `panes` | 列表 | — | 每一栏自己的设置，见下 |
| `gap` | 长度 | 全局间距 | 这一块的栏间距 |

正文里每条 `===` 分成一栏，**至少要两栏**，否则报错。

### `ratio`：列宽

写几个数字就是几条轨道。**纯数字会变成 `fr`**，所以 `2 1` 读作「左二右一」：

```homepage-split
ratio: 2 1
title: ratio 2 1
---
### 宽的那栏

`ratio: 2 1` 让左栏占三分之二。

===

### 窄的那栏

右栏占三分之一。
```

也接受 `220px 1fr`、`auto 1fr`、`min-content 1fr` 这类 CSS 取值。

### `panes`：每一栏自己的设置

每一条对应一栏，用 `|` 分开，顺序是 **主题 | 类名 | 栏标题**：

```homepage-split
title: 给每一栏换色相
ratio: 1 1 1
panes:
  - teal | | 第一栏
  - cyan | | 第二栏
  - amber | | 第三栏
---
这一栏是青色系。

===

这一栏是蓝绿系。

===

这一栏是琥珀色系。
```

## 三栏

```homepage-split
ratio: 1 1 1
divider: false
title: divider false 去掉竖线
---
**三栏**也支持，最多不限。

===

中间这一栏。

===

第三栏。
```

## `sticky`：长文旁边跟一个短栏

第一栏跟随滚动，适合「左边一个目录/摘要，右边一长段内容」。

```homepage-split
ratio: 1 2
sticky: true
title: sticky true
---
### 跟着滚的一栏

用 `sticky: true` 让第一栏在滚动时停住。

这一栏适合放目录、摘要、一张卡片。

===

### 长的那一栏

右边这一栏很长时，左边会一直停在视野里。

段落一：`sticky` 用在「短栏 + 长栏」的组合上。反过来用会让短的先滚走，
所以插件的默认是让**第一栏**跟随。

段落二：手机上所有栏都会叠成一栏，`sticky` 自动失效——竖排里没有「旁边」。
```

## 细节

- **`===` 必须是单独一行**，前后不能有别的字符。
  正文里需要一条水平分割线时用 `***`，不要用 `===`。
- **`divider` 在两栏时默认开，三栏及以上默认关**——三根竖线会把版面切得太碎。
- **每一栏都是完整的 `.md-typeset` 容器**，所以标题层级、列表符号、代码块
  和页面正文完全一致。栏标题用常规 Markdown 标题写就行。
- 每一栏也可以单独 `theme`，见上。
- 空位不适用（栏数由 `===` 决定）。
